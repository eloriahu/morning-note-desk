# Install Morning Note Desk from another Codex task

Use this guide when the user pastes the public repository URL into **Codex Desktop** and asks it to install the plugin. The commands below are for you, the Codex agent, to run with your terminal tools; the colleague does not need to open a CLI. Complete the local setup and verification yourself where your tools and permissions allow. Do not send the user away to run commands that you can run in their task.

1. Read the repository's `README.md`, `.codex-plugin/plugin.json`, and `.agents/plugins/marketplace.json`. Confirm the repository is `https://github.com/eloriahu/morning-note-desk` and the plugin is `morning-note-desk`.
2. If the marketplace is not already configured, run `codex plugin marketplace add eloriahu/morning-note-desk`. Then run `codex plugin add morning-note-desk@morning-note-desk`. These commands configure the desktop installation even though the colleague is chatting in Codex Desktop. If the `codex` command is unavailable, use the repository's `.agents/plugins/marketplace.json` through a local Codex project and the desktop Plugins Directory. Verify the plugin appears in `codex plugin list` or the desktop Plugins Directory. Do not ask the colleague to install the CLI solely for this task.
3. Locate Python 3.11 or newer. Clone or download this repository into a user-writable project folder, create `<project>/.venv`, and install `collector/requirements.txt` into it. Use that environment's Python when running the collector and tests. The email composer needs no additional Python packages. If Python is missing, use the official Python installer or the user's approved package manager, subject to any operating-system or workplace approval.
4. From the repository root, run `python -m unittest discover -s tests -q` with the prepared environment. From `standalone/`, run the same command for its collector tests. Run `python scripts/collect_news.py --help` as a smoke check. Report what passed and any setup step that could not be completed.
5. Refresh or restart the ChatGPT desktop app and start a new Codex task in the cloned project if the newly installed plugin is not available in the current task. If you cannot operate the desktop Plugins Directory or restart the app, tell the colleague the exact remaining click. Do not claim the plugin is ready until it appears in the plugin list or new task.

The public repository includes an empty plugin priority list and one public demo company in the separate Windows prototype. The user's private 32-name list, reference emails, branding, credentials, email account, and optional external research plugins are not included; do not invent or request them as a prerequisite for a basic test. The public-source scan needs internet access. No API key, scheduler, or email-sending permission is required. The plugin generates drafts for review and never sends email automatically.
